# 📖 Sobre o Projeto

O *GravityShield* é uma plataforma web desenvolvida para conscientizar e apresentar soluções relacionadas aos impactos da ausência de gravidade no corpo humano durante missões espaciais de longa duração.

O projeto combina tecnologia, educação e interatividade para demonstrar como sistemas inteligentes podem auxiliar no monitoramento da saúde de astronautas, reduzindo riscos fisiológicos causados pela microgravidade.

Além da apresentação do problema e da solução proposta, o sistema oferece recursos interativos que tornam a experiência do usuário mais dinâmica e educativa. :contentReference[oaicite:0]{index=0}

---

# 🎯 Objetivos

- Explicar os efeitos da microgravidade no organismo humano.
- Apresentar a proposta GravityShield como solução tecnológica.
- Demonstrar conceitos de monitoramento inteligente da saúde.
- Incentivar o aprendizado sobre exploração espacial.
- Aplicar conceitos de desenvolvimento web moderno.
